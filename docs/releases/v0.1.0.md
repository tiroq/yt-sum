# YT Sum v0.1.0

Initial release: local-first YouTube transcript and summarization app with browser extension and real-time pipeline diagnostics.

## Features

- **Browser Extension**: Add videos to the queue from YouTube pages via Manifest V3 extension
- **Job Retry & Auto-Retry**: Automatically retry failed processing steps; manual retry on-demand with configurable max attempts
- **Video Management**: Delete videos from app or disk; archive videos with filtering; rescan library to remove stale entries
- **Playlist Support**: Import and manage playlists; extract playlist URLs with metadata
- **Text-to-Speech**: Generate audio from summaries with markdown support
- **Provider Control**: Enable/disable providers; configure rate limits (requests/minute, tokens/minute)
- **Pipeline Diagnostics**: Queue status dashboard, health endpoint with job metrics, pipeline stage tracking
- **System Controls**: Start/stop/restart API; database reset with backup; health checks
- **Audio Improvements**: WAV format with fallback; UUID-based temp files; better diagnostics on transcription errors
- **Accessibility**: Keyboard controls for UI; tooltips; semantic HTML labels; multi-language support (Russian localizations)
- **Strict Testing**: 100% coverage gates for JavaScript and Python; comprehensive test suite for public APIs

## Breaking Changes

None.
